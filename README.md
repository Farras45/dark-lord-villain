A 100-word villain monologue for make.fun's "The Tired Dark Lord" bounty: Fenwick, keeper of the Drowned Bridge, has collected one memory as toll from every soul crossing his river for forty years — and tonight the toll rises to your name. The tiredness lives in the pauses, the lost thread and the small deflections, never in a plain statement, and the sting lands in the last line.

## Run it

```sh
node main.ts
```

This writes the monologue to `/output/entry.txt` (exactly 100 words, under the 600-character gate).
